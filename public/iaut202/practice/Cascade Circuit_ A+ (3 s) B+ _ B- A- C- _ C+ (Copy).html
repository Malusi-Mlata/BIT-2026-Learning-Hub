Cascade Circuit: A+ → 3 s → B+ | B− A− C− | C+

One Start press = one cycle. All limit switches are normally open (NO). Cylinder A uses a magnetic (reed) sensor for A1.

4. How it runs

#What happens
1Press Start with C extended (C1 closed): K1 latches, Y1 energises, A+ .
2A reaches the end: magnetic sensor A1 closes, timer T1 runs 3 s, then Y3 gives B+ .
3B1 closes: K2 latches, K1 drops. Y4, Y2, Y6 energise together: B− , A− , C− .
4A0, B0 and C0 all closed: K3 latches, K2 drops. Y5 energises: C+ .
5C1 closes, cycle ends and waits for the next Start (release the button).

Assumption: C starts extended, because the sequence has C− before C+. Y1/Y2 = A+/A−, Y3/Y4 = B+/B−, Y5/Y6 = C+/C−.
